virsh Cheat Sheet

QEMU / KVM · libvirt · qemu-iso-lab — bignami dei comandi più usati, ereditato da kvm-lab
connessione: qemu:///system
<VM> = nome dominio · es. debian-server dopo vmctl export-libvirt
placeholder in arancio

≣ Inventario & stato

virsh list --all
Tutte le VM (accese e spente) con stato.
virsh list --state-running
Solo quelle in esecuzione.
virsh domstate <VM>
Stato singolo: running / shut off / paused.
virsh dominfo <VM>
CPU, RAM, autostart, persistenza, UUID.
virsh domid <VM> # id numerico (solo se accesa)
virsh domifaddr <VM>
Indirizzi IP (richiede guest-agent o DHCP lease).

⏻ Avvio & spegnimento

virsh start <VM>
Avvia la VM.
virsh shutdown <VM>
Spegnimento ordinato (ACPI). Richiede SO che risponde.
virsh reboot <VM>
Riavvio ordinato.
virsh destroy <VM>
Spegnimento forzato (stacca la spina).
virsh suspend <VM> # pausa virsh resume <VM> # riprendi
virsh autostart <VM> # on al boot host virsh autostart --disable <VM>

▣ Console & schermo

virt-viewer <VM> # GUI SPICE/VNC
Finestra grafica della VM (pacchetto virt-viewer).
virsh console <VM>
Console seriale testuale (esci con Ctrl+]).
virsh screenshot <VM> shot.ppm convert shot.ppm shot.png # ImageMagick
Cattura lo schermo. Converti il .ppm in .png.
virsh send-key <VM> KEY_SPACE # sveglia virsh send-key <VM> KEY_ESC
Tasti al guest: utile per uscire dal salvaschermo prima dello screenshot.
virsh send-key <VM> KEY_LEFTCTRL KEY_LEFTALT KEY_DELETE
Ctrl-Alt-Canc al guest.

◇ Guest agent (in-VM)

virsh qemu-agent-command <VM> \ '{"execute":"guest-ping"}'
Verifica che l'agente risponda (OS avviato e pronto).
virsh qemu-agent-command <VM> \ '{"execute":"guest-get-osinfo"}'
Nome/versione SO dal guest (utile su Windows).
virsh domtime <VM> --sync
Sincronizza l'orologio del guest via agente.
# esegui un comando nel guest Linux guest-exec → path:/bin/sh arg:["-c","..."]
Su Windows: path cmd.exe, arg ["/c","..."]. Poi guest-exec-status col pid per l'output.

▤ Dischi & storage pool

virsh domblklist <VM>
Dischi/ISO collegati e relativi path.
virsh pool-list --all virsh pool-info <pool> virsh pool-refresh <pool> # dopo aver aggiunto file
virsh vol-list <pool> virsh vol-info --pool <pool> <vol>
qemu-img info disco.qcow2 qemu-img create -f qcow2 -o preallocation=off new.qcow2 20G
virt-cat -a disco.qcow2 /var/log/syslog
Legge file dentro il disco a VM spenta (libguestfs) — ottimo per diagnosi install fallite.

Dischi vmctl: artifacts/<vm>/disk.qcow2 · NVRAM: artifacts/<vm>/OVMF_VARS.fd · pool kvm-lab: hdd · shared · Linux · Windows · addons

⇄ Rete

virsh net-list --all virsh net-info default virsh net-dhcp-leases default
Reti virtuali e lease DHCP assegnati.
virsh domiflist <VM>
Interfacce di rete della VM (modello, MAC, bridge).
virsh net-dumpxml lab-lan virsh net-start lab-lan · virsh net-autostart lab-lan
La LAN isolata del network lab (bridge virbr-lab, host .254), creata da vmctl export-libvirt.

⧉ Snapshot

virsh snapshot-create-as <VM> nome \ "descrizione"
Crea uno snapshot (disco+RAM se accesa).
virsh snapshot-list <VM> virsh snapshot-revert <VM> nome virsh snapshot-delete <VM> nome

</> Definizione & XML

virsh dumpxml <VM> > vm.xml
Esporta la configurazione XML.
virsh edit <VM> # modifica + valida
virsh define vm.xml # crea/aggiorna da file
virsh dominfo <VM> | grep Persistent
Persistente vs transitoria.

⚠ Eliminare una VM (sicuro)

# 1. cancella SOLO il disco principale virsh vol-delete --pool hdd <nome>.qcow2 # 2. rimuovi la definizione (+ NVRAM se UEFI) virsh undefine <VM> --nvram
MAI virsh undefine --remove-all-storage: cancella tutti i volumi registrati, incluse le ISO nei pool (Windows, Linux, addons…) → perdita irreversibile.
vmctl unexport-libvirt <vm> # VM esportata da vmctl
Toglie la definizione, conserva disco e NVRAM in artifacts/. Poi vmctl clean <vm> se si vuole anche il disco.

✛ Diagnostica

virsh dominfo <VM> virsh domstats <VM> # cpu/mem/blk/net live
virsh domblkerror <VM> # errori I/O disco virsh domblkstat <VM> vda
sudo virsh dommemstat <VM>
Statistiche memoria (richiede balloon/agent).
journalctl -u libvirtd --since today cat /var/log/libvirt/qemu/<VM>.log
Log host del processo QEMU della VM.

⊟ Cartella condivisa (virtiofs)

La VM deve avere memory backing memfd e il filesystem virtiofs; sul guest Windows serve WinFSP. È l'XML che vmctl export-libvirt genera per i profili con shared_dir.
<memoryBacking> <source type='memfd'/> <access mode='shared'/> </memoryBacking> <filesystem type='mount' accessmode='passthrough'> <driver type='virtiofs'/> <source dir='…/storage/shared/'/> <target dir='shared'/> </filesystem>

⌘ vmctl ↔ virsh

vmctl stop <vm> vmctl export-libvirt <vm> [--dry-run] [--replace]
Installa e provisiona con QEMU puro, poi consegna a libvirt: XML in artifacts/<vm>/libvirt/, disco per percorso assoluto, mai copiato.
virsh start <vm> · virt-viewer <vm> virsh domifaddr <vm> → ssh utente@IP
Dopo l'export si usa virsh/virt-manager; la porta hostfwd di vmctl shell non esiste più: SSH sulla 22 dell'IP DHCP.
vmctl lab install · vmctl lab up # network lab vmctl export-libvirt pfsense-lab # crea anche lab-lan
Su QEMU puro l'host entra dai forward del router (127.0.0.1:8080…); su libvirt sta a 192.168.0.254.
virsh shutdown <vm> # fino a "shut off" vmctl unexport-libvirt <vm> · vmctl start <vm>
Ritorno a vmctl. Mai lo stesso disco acceso in QEMU e in libvirt insieme.
